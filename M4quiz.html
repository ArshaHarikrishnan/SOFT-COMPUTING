Module 4 – Fuzzy Inference System & Genetic Algorithm

Teaching plan: 6 hours | Course Outcome: CO4

Syllabus coverage: Mamdani and Sugeno FIS; fuzzy logic controller; genetic algorithm concepts; chromosome coding/encoding; selection, crossover and mutation operators; stopping conditions.

1. Fuzzy Inference System (FIS)

A Fuzzy Inference System maps inputs to outputs using fuzzy sets, linguistic rules and an inference mechanism.

  • Fuzzification: converts crisp input values into membership grades.
  • Database: stores definitions and parameters of membership functions.
  • Rule base: stores linguistic IF–THEN rules.
  • Inference engine: evaluates rules and combines their results.
  • Defuzzification: converts the aggregated fuzzy output into a crisp value when required.
Crisp inputs → Fuzzification → Inference engine + Rule base/Database → Defuzzification → Crisp output

2. Mamdani FIS

  • Rule consequents are fuzzy sets.
  • Antecedent membership values are evaluated using fuzzy operators such as AND (commonly min) and OR (commonly max).
  • Rule outputs are combined using an aggregation operator, often max.
  • The aggregated fuzzy output is converted to a crisp value using a defuzzification method such as centroid.

Example rule: IF temperature is High AND humidity is High THEN fan speed is Fast.

3. Sugeno FIS

  • Rule consequents are constants (zero-order Sugeno) or functions of the inputs (first-order Sugeno).
  • Each rule produces a crisp consequent value or function, weighted by its firing strength.
  • The final output is commonly obtained using a weighted average.
Rule i: IF x is Ai AND y is Bi THEN zi = fi(x,y)
Output = Σ(wi zi) / Σwi

5. Fuzzy Logic Controller (FLC)

An FLC uses fuzzy logic to control a system when an exact mathematical model may be difficult to formulate.

  • Define input and output variables and their universes of discourse.
  • Choose linguistic terms and membership functions.
  • Construct the rule base using expert knowledge.
  • Fuzzify sensor/input values and evaluate the rules.
  • Aggregate the rule outputs and defuzzify to obtain the control action.
Illustrative rule: IF temperature is High AND humidity is Low THEN fan speed is Fast. The actual controller requires defined membership functions and a complete rule base.

6. Genetic Algorithm (GA)

A Genetic Algorithm is a population-based search and optimisation method inspired by natural selection and evolution. Candidate solutions are represented as chromosomes.

  1. Encode candidate solutions and initialise a population.
  2. Evaluate the fitness of each chromosome.
  3. Select parent chromosomes according to a selection strategy.
  4. Apply crossover to create offspring.
  5. Apply mutation to introduce variation.
  6. Form the next population and evaluate fitness.
  7. Repeat until a stopping condition is met; return the best solution found.

7. Chromosome Encoding

  • Binary encoding: chromosome is a string of 0s and 1s.
  • Value encoding: genes contain values such as real numbers, characters or other problem-specific values.
  • Permutation encoding: chromosome is an ordering of items; useful for ordering or route problems.

8. Selection Operators

  • Roulette-wheel selection: selection probability is proportional to fitness (for a maximisation problem with non-negative fitness values).
  • Stochastic universal sampling: uses multiple evenly spaced pointers on the cumulative fitness scale to select a set of parents with lower sampling variance.
  • Tournament selection: randomly choose a group of competitors and select the best among them; tournament size controls selection pressure.
  • Rank-based selection: assigns selection probabilities based on fitness rank rather than raw fitness magnitude.
Roulette probability: pi = fi / Σ fj

9. Crossover Operators

  • Single-point: choose one cut point and exchange the tails of two parents.
  • Two-point: choose two cut points and exchange the segment between them.
  • Uniform: choose each gene from either parent according to a mask or probability.
  • Other methods in the question bank include three-parent, shuffle and precedence-preservative crossover; the operator must suit the chromosome representation.

10. Mutation Operators

  • Bit-flip: change a binary gene from 0 to 1 or 1 to 0.
  • Random resetting: replace a selected value gene with another valid value.
  • Swap: exchange the positions of two genes in a permutation.
  • Inversion: reverse the order of genes in a selected permutation segment.

Mutation helps maintain population diversity and reduces premature convergence. Mutation rates should be chosen carefully.

11. Stopping Conditions

  • Maximum number of generations reached.
  • A required fitness threshold or acceptable solution quality is achieved.
  • Population has converged or fitness improvement has become negligible for a specified period.
  • A computational time or evaluation budget is exhausted.
Exam focus: Draw and compare Mamdani/Sugeno architectures; explain FLC; trace GA steps; solve roulette-wheel selection; demonstrate encoding, crossover and mutation; state stopping conditions.
