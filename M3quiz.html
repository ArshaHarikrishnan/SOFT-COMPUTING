Module 3 – Fuzzy Logic & Defuzzification

Teaching plan: 8 hours | Course Outcome: CO3

This page follows the CST444 Module 3 syllabus: fuzzy sets, properties and operations; membership functions and fuzzification; membership-value assignment; fuzzy relations; propositions and implications; λ-cuts; and defuzzification.

1. Fuzzy Sets and Membership Functions

  • A fuzzy set A on universe X is described by membership function μA(x), assigning each element a degree from 0 to 1.
  • μA(x)=0 means no membership; μA(x)=1 means full membership; intermediate values indicate partial membership.
  • A crisp set permits only 0 or 1; a fuzzy set permits gradual membership.
  • Fuzzification converts a crisp input into membership values in fuzzy sets.
A = { (x, μA(x)) | x ∈ X }, where 0 ≤ μA(x) ≤ 1

2. Support, Core and Boundary

  • Support: elements for which μA(x) > 0.
  • Core: elements for which μA(x) = 1.
  • Boundary: elements for which 0 < μA(x) < 1.

3. Basic Fuzzy Set Operations

Complement: μĀ(x) = 1 − μA(x)
Union: μA∪B(x) = max(μA(x), μB(x))
Intersection: μA∩B(x) = min(μA(x), μB(x))

Apply these operations element by element for sets defined on the same universe.

4. Algebraic and Bounded Operations

Algebraic product: μA·B = μA × μB
Algebraic sum: μA⊕B = μA + μB − (μA × μB)
Bounded sum: μA⊞B = min(1, μA + μB)
Bounded difference: μA⊖B = max(0, μA + μB − 1)
Example: If μA=0.4 and μB=0.7: intersection=0.4, union=0.7, complement of A=0.6, algebraic product=0.28, algebraic sum=0.82, bounded sum=1 and bounded difference=0.1.

5. Membership-Value Assignment

  • Intuition: assign values using experience or judgement about the problem.
  • Inference: derive values from available facts, rules or relationships.
  • Rank ordering: rank elements by relative importance or degree, then assign membership values based on that order.

6. Fuzzy Relations and Cartesian Product

  • A fuzzy relation represents the degree of association between elements of two or more universes.
  • The Cartesian product of fuzzy sets A and B can be represented as a relation R on X × Y.
  • For the standard min-based Cartesian product, μR(x,y)=min(μA(x), μB(y)).

7. Composition of Fuzzy Relations

Max–min: μR∘S(x,z) = max over y [ min(μR(x,y), μS(y,z)) ]
Max–product: μR∘S(x,z) = max over y [ μR(x,y) × μS(y,z) ]

For relation R between X and Y and S between Y and Z, composition produces a relation between X and Z.

8. Fuzzy Tolerance and Equivalence Relations

  • Reflexive: every element is fully related to itself.
  • Symmetric: μR(x,y)=μR(y,x).
  • Max–min transitive: μR(x,z) ≥ max over y min(μR(x,y), μR(y,z)).
  • A fuzzy tolerance relation is reflexive and symmetric. A fuzzy equivalence relation also satisfies the required transitivity property.

9. Fuzzy Propositions and Implications

  • A fuzzy proposition is a statement involving a linguistic variable and fuzzy value, e.g. “temperature is warm”.
  • A fuzzy implication expresses a fuzzy IF–THEN relationship between propositions.
  • Fuzzy rules represent approximate reasoning where boundaries are not sharply defined.

10. λ-Cuts and Strong λ-Cuts

λ-cut: Aλ = {x ∈ X | μA(x) ≥ λ}
Strong λ-cut: Aλ⁺ = {x ∈ X | μA(x) > λ}

A λ-cut converts a fuzzy set into a crisp set by selecting elements whose membership is at least the threshold. A strong λ-cut uses a strict greater-than comparison.

11. Defuzzification

Defuzzification converts the fuzzy output of a fuzzy system into a crisp numerical value for a final decision or control action.

  • Centroid / centre of area: centre of gravity of the aggregated output membership function.
  • Bisector of area: divides the area under the membership function into two equal parts.
  • Mean of maxima: averages the values at which membership reaches its maximum.
  • Smallest / largest of maxima: selects the smallest or largest value among those with maximum membership.
  • Weighted average: combines output values using their weights, commonly with suitable singleton consequents.
Exam focus: Practise fuzzy-set operations, membership-function sketches, Cartesian products, max–min and max–product composition, λ-cuts and defuzzification methods.
