Module-wise Tutorials

Practice, apply and strengthen the concepts covered in all five modules of CST444 – Soft Computing.

Important instruction — Every question is compulsory All students must complete every tutorial question in every module (Modules 1–5). These are not roll-number-wise assignments. Do not attempt only selected questions. Write complete solutions, show intermediate calculations and include neat, labelled diagrams wherever required.
Module 1

Introduction to Soft Computing & Artificial Neural Network

15 questions

Complete all questions. The original tutorial sheet includes the X and O pattern-recognition problem; use the pattern illustration in the supplied sheet.

  1. 1.Describe the necessity of an activation function. Examine the various aspects of the sigmoidal activation function and list its drawbacks. Calculate the net output of the given neural network using bipolar and binary sigmoidal activation functions.
  2. 2.A 4-input neuron has weights 1, 2, 3 and 4. The transfer function is linear with the constant of proportionality equal to 2. The inputs are 4, 10, 5 and 20 respectively. Predict the output.
  3. 3.Construct a feed-forward network with 5 inputs, three hidden nodes and four output nodes. Draw and label the architecture.
  4. 4.Design an MP neuron using s(a₁,a₂,a₃) = a₁a₂a₃ using bipolar inputs and targets.
  5. 5.Implement the NAND gate using an MP neuron. Show the truth table, threshold and weights.
  6. 6.Implement the NOR gate using an MP neuron. Show the truth table, threshold and weights.
  7. 7.Show that the derivative of the unipolar sigmoid function is f′(x) = λ f(x)[1 − f(x)].
  8. 8.Show that the derivative of the bipolar sigmoid function is f′(x) = (λ/2)[1 + f(x)][1 − f(x)].
  9. 9.Design a Hebb net to implement the AND function. Show the weight updates.
  10. 10.Design a Hebb net to implement the OR function. Show the weight updates.
  11. 11.Design a Hebb net to implement the XOR function. Show the training patterns and test the response.
  12. 12.Design a Hebb net to implement the AND function using (a) binary input and target value and (b) binary input and bipolar target value.
  13. 13.Implement the NOR function using a Hebb net using (a) bipolar input and target and (b) bipolar input and binary target.
  14. 14.Using Hebb's rule, find the weights for the classification problem: (1, −1, 1, −1) and (1, 1, 1, −1) belong to class +1; (−1, −1, 1, 1) and (1, 1, −1, −1) belong to class −1. Test the network using each training vector.
  15. 15.Distinguish between the patterns “X” and “O” using a suitable neural network. Use the pattern grids shown in the original tutorial sheet and explain the representation.
Module 2

Supervised Learning Network

7 questions

Complete all questions. Reproduce the pattern grids from the original tutorial sheet wherever indicated.

  1. 1.Implement the NOR function using bipolar inputs and targets.
  2. 2.Using the perceptron rule, find the weights required to classify the two 3 × 3 patterns shown in the original tutorial sheet. The “I” pattern belongs to the class (target +1), and the “F” pattern does not belong to the class (target −1). Show the input encoding and training iterations.
  3. 3.Using a perceptron network, classify the vectors (1, 1, −1, −1) and (1, −1, 1, −1) as class +1, and (−1, −1, −1, 1) and (−1, −1, 1, 1) as class −1. Assume learning rate 1 and initial weights 0.
  4. 4.Classify the two-dimensional pattern shown in the original tutorial sheet using a perceptron network. Draw the decision boundary and explain the classification.
  5. 5.Implement the AND function using an ADALINE network. Show the architecture, training and testing.
  6. 6.Using the delta rule, find the weights for the classification problem: (1, 1, −1, −1) and (−1, −1, −1, −1) belong to class +1; (1, 1, 1, 1) and (−1, −1, 1, −1) belong to class −1. Use learning rate 0.5 and assumed initial random weights. Test the network.
  7. 7.Using a backpropagation network, find the new weights for the network and input pattern shown in the original tutorial sheet. The target output is 1 and the learning rate is 0.3. Show the forward pass, error calculation and backward weight updates.

  2. 2.For X = {2, 4, 6, 8, 10}, find its power set, the cardinality of the set and the cardinality of its power set.
  3. 3.Verify De Morgan’s laws for the fuzzy membership functions given in the original tutorial sheet.
  4. 4.Consider the two fuzzy sets A and B specified in the original tutorial sheet. Find their union, intersection, complements and the other indicated fuzzy-set operations.
  5. 5.Using the liquid-level controller example and the supplied flow-speed/control-level membership table, calculate all membership values and fuzzy-set operations requested in the worksheet.
  6. 6.For the two membership functions given in the worksheet, calculate the union, intersection, complements and the indicated combined fuzzy sets.
  7. 7.Let X be the universe of interest/sales and consider the fuzzy sets Low, Medium and High given in the worksheet. Find each listed fuzzy-set operation, including the specified unions, intersections and complements.
  8. 8.For the nondimensional membership functions μA and μB given in the worksheet, calculate all requested operations involving μA, μB and their complements.
  9. 9.Consider the LAN example and the two fuzzy sets μA(x) and μB(x) given in the worksheet. Perform algebraic sum, algebraic product, bounded sum and bounded difference.
  10. 10.Given the two fuzzy sets in the worksheet, evaluate each requested operation, including algebraic sum, algebraic product, bounded sum and bounded difference.
  11. 11.Given the crisp sets X and Y in the worksheet, find the Cartesian products A × B and B × C.
  12. 12.For the two fuzzy sets A and B given in the worksheet, find the fuzzy relation by performing the Cartesian product over the given fuzzy sets.

  16. 16.Using the three fuzzy membership functions for the medicinal-research example, form the requested relations and find their compositions using max–min and max–product methods.
  17. 17.For the athletic-race example, use the Low, Medium and High fuzzy sets to find the requested Cartesian products and compositions using max–min and max–product methods.

Module 4

Fuzzy Inference System & Genetic Algorithm

10 questions
  1. 1.Explain the architecture and working of a Mamdani fuzzy inference system. Draw a labelled block diagram showing fuzzification, rule base, inference engine and defuzzification.
  2. 2.Explain the architecture and working of a Sugeno fuzzy inference system. Distinguish zero-order and first-order Sugeno models with suitable examples.
  3. 3.Compare Mamdani and Sugeno fuzzy inference systems with respect to rule consequent, output representation, computation and applications.
  4. 4.Design a fuzzy logic controller for room-temperature control. Identify input and output variables, define suitable linguistic terms and membership functions, and construct at least five IF–THEN rules.
  5. 5.Explain the stages of a fuzzy logic controller and demonstrate how a crisp input is converted into a crisp control output.
  6. 6.Explain the basic concepts and working cycle of a genetic algorithm with a neat flowchart. Identify population, chromosome, gene, fitness and generation.
  7. 7.Encode the decision variable x ∈ {0, 1, …, 31} as a binary chromosome. Explain the chromosome length and decode the strings with examples.
  8. 8.Given a population and fitness values of your choice, demonstrate roulette-wheel selection. Calculate the selection probability and cumulative probability of each chromosome.
  9. 9.Demonstrate single-point and two-point crossover using suitable binary parent chromosomes. Show the offspring produced.
  10. 10.Demonstrate bit-flip mutation on a binary chromosome. Explain mutation rate and discuss suitable stopping conditions for a genetic algorithm.
Module 5

Multi-Objective Optimization & Hybrid Systems

10 questions
  1. 1.Define a multi-objective optimization problem (MOOP). Formulate a general MOOP with two objective functions and constraints.
  2. 2.Differentiate single-objective and multi-objective optimization with a practical example.
  3. 3.Explain the principles of multi-objective optimization. Why may a single solution not optimize all objectives simultaneously?
  4. 4.Define dominance, weak dominance, strict dominance and non-dominance. Illustrate each using a small set of two-objective candidate solutions.
  5. 5.Determine the non-dominated set from at least six candidate solutions for a two-objective minimization problem. Show pairwise comparisons and identify the Pareto front.
  6. 6.Explain Pareto optimality and Pareto-optimal solutions. Draw a two-objective plot showing dominated and non-dominated solutions.
  7. 7.Discuss the optimality conditions in multi-objective optimization and explain how they differ from scalar single-objective optimality.
  8. 8.Explain the architecture and working of a neuro-fuzzy hybrid system with a labelled block diagram. Describe how neural learning can tune a fuzzy system.
  9. 9.Explain genetic–neuro hybrid systems. Draw a block diagram and describe how a genetic algorithm can optimize neural-network parameters or architecture.
  10. 10.Compare neuro-fuzzy and genetic–neuro hybrid systems in terms of architecture, learning/optimization mechanism, advantages and applications.
