Course Modules

35 lecture hours organised across five modules

Module 01 • 6 Hours

Introduction to Soft Computing & ANN

Foundations of soft computing and basic artificial neural network models.

  • Hard vs Soft Computing
  • Biological vs Artificial Neurons
  • Activation Functions
  • McCulloch–Pitts Neuron
  • Hebb Network
Open Module 1 →
Module 02 • 7 Hours

Supervised Learning Network

Supervised neural network models, training algorithms and practical problems.

  • Perceptron Networks
  • Learning Rule
  • Adaline
  • Training & Testing
  • Back Propagation
Open Module 2 →
Module 03 • 8 Hours

Fuzzy Logic & Defuzzification

Fuzzy sets, membership functions, relations, propositions and defuzzification.

  • Fuzzy Sets & Operations
  • Membership Functions
  • Fuzzy Relations
  • Fuzzy Propositions
  • Lambda Cuts & Defuzzification
Open Module 3 →
Module 04 • 6 Hours

Fuzzy Inference System & GA

Fuzzy inference systems and the fundamental operators of genetic algorithms.

  • Mamdani Type
  • Sugeno Type
  • Fuzzy Logic Controller
  • GA Coding & Selection
  • Crossover & Mutation
Open Module 4 →
Module 05 • 8 Hours

Multi-Objective Optimization & Hybrid Systems

Multi-objective optimisation, Pareto optimality and hybrid soft computing approaches.

  • Linear & Nonlinear MOOP
  • Convex & Non-convex MOOP
  • Dominance
  • Pareto Optimality
  • Neuro-Fuzzy & Genetic-Neuro Systems
Open Module 5 →

Course Outcomes

Expected learning outcomes for CST444

CO1

Describe soft computing techniques and the basic models of Artificial Neural Network.

CO2

Solve practical problems using neural networks.

CO3

Illustrate the operations, model and applications of fuzzy logic.

CO4

Illustrate the concepts of Genetic Algorithm.

CO5

Describe the concepts of multi-objective optimization models and the need for using hybrid soft computing approaches.
