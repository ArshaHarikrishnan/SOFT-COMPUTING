Module Learning Focus

Soft Computing Foundations

Understand the introduction to Soft Computing, the distinction between Hard Computing and Soft Computing, and applications of Soft Computing.

Artificial Neural Networks

Study artificial neurons in comparison with biological neurons and the basic models of Artificial Neural Networks, including connections and learning.

Activation Functions

Study the role of activation functions in artificial neural network models.

McCulloch–Pitts Neuron

Study the McCulloch and Pitts neuron model and its use in neural-network based logical processing.

Hebb Network

Study the Hebb network as included in the Module 1 syllabus.

Exam focus: The syllabus assessment questions include activation functions, the McCulloch–Pitts neuron model, NAND implementation using the M-P model, and Hebb network-related questions.

Course-Level Assessment Questions from Module 1

  1. Describe the necessity of Activation function. Examine the various aspects of sigmoidal activation function and list the drawbacks. Calculate the net output of the given neural network using bipolar and binary sigmoidal activation functions.
  2. Explain the architecture of McCulloch-Pitts Neuron network model. Implement NAND (NOT-AND) gate function using M-P Neuron Model with binary input.
