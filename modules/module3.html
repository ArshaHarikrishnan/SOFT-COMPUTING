MODULE 3 • FUZZY LOGIC & DEFUZZIFICATION

Fuzzy Sets, Relations & Defuzzification

This module introduces fuzzy sets, their properties and operations, fuzzy membership functions, fuzzification, membership-value assignment methods, fuzzy relations, fuzzy propositions, fuzzy implications, λ-cuts and defuzzification methods.

Assessment & Practice Questions

Questions drawn from the CST444 course-level assessment and model-question material.

Fuzzy Set Operations: Given two fuzzy sets, find the algebraic sum, algebraic product and bounded sum.
Membership Functions: Using your own intuition and definition of the universe of discourse, plot membership functions for liquid level in a tank using the linguistic terms Empty, Very Less, Less, Full and Very Full.
Fuzzy Relations: Find the Cartesian product of given fuzzy sets and represent it as a fuzzy relation.
Composition: Given fuzzy relations, determine the composition using max-min composition.
Composition: Given fuzzy relations, determine the composition using max-product composition.
