Module 2 – Supervised Learning Network

Teaching plan: 7 hours | Course Outcome: CO2

This revision section follows the CST444 Module 2 syllabus: Perceptron learning and testing, ADALINE, Delta/Widrow–Hoff learning, and Back Propagation Network.

1. Perceptron Network

  • A perceptron is a supervised learning model used for classification. It computes a weighted sum of inputs and applies a threshold/activation function.
  • Training uses labelled input patterns. The weights are adjusted when the predicted class differs from the target class.
  • Testing uses the trained weights to classify previously unseen input patterns; weights are not updated during testing.
net = Σ(wᵢxᵢ) + b
y = f(net)
wᵢ(new) = wᵢ(old) + η(t − y)xᵢ

Here, η is the learning rate, t is the target and y is the predicted output. Bias can be treated as a weight connected to a constant input.

2. Perceptron training and testing

  • Initialize weights and bias (often to zero) and choose a learning rate.
  • For each training pattern, calculate net input and predicted output.
  • Compare predicted output with target; update weights and bias according to the learning rule.
  • Repeat for the required epochs or until all training patterns are classified correctly.
  • For testing, calculate the output using the final weights and classify the input. Do not update weights.
Important limitation: A single-layer perceptron can learn linearly separable patterns. It cannot learn XOR using one linear decision boundary.

3. ADALINE (Adaptive Linear Neuron)

  • ADALINE is a single-layer network that uses a linear combiner during learning.
  • The net input is compared with the target to calculate the error.
  • Weight updates minimize the sum/mean of squared errors. The threshold decision is applied after the linear output when classification is required.
yᵢ = Σ(wⱼxᵢⱼ) + b
eᵢ = tᵢ − yᵢ
wⱼ(new) = wⱼ(old) + η eᵢ xᵢⱼ
b(new) = b(old) + η eᵢ

4. Delta Rule / Widrow–Hoff / LMS Rule

  • The Delta Rule adjusts weights in proportion to the error and the corresponding input.
  • Widrow–Hoff learning is also called the Least Mean Squares (LMS) rule.
  • The learning rate controls the size of each weight adjustment. A value that is too large may cause unstable learning.
  • Mean squared error (MSE) measures average squared difference between target and linear output.
MSE = (1/N) Σ(tᵢ − yᵢ)²

5. Back Propagation Network (BPN)

  • BPN is a multilayer feed-forward neural network trained using supervised learning.
  • It typically contains an input layer, one or more hidden layers and an output layer.
  • Forward pass: inputs move layer by layer; each neuron computes net input and activation output.
  • Error calculation: compare the network output with the target.
  • Backward pass: propagate error information from output layer towards hidden layers and calculate error terms.
  • Weight update: adjust weights using the learning rate and calculated error terms. Repeat over training patterns and epochs.
Output-layer error term: δₖ = (tₖ − oₖ) f′(netₖ)
Hidden-layer error term: δⱼ = f′(netⱼ) Σₖ(δₖ wⱼₖ)

For sigmoid activation, the derivative can be expressed using the neuron's output. A differentiable activation function is needed to calculate gradients during backpropagation.

6. Perceptron vs ADALINE

PerceptronADALINE
Uses classification output/error for weight correction.Uses linear combiner error for weight correction.
Uses perceptron learning rule.Uses Delta/Widrow–Hoff (LMS) rule.
Learns linearly separable classifications.Adjusts weights to minimize squared error.
Exam focus: Practise perceptron weight updates, ADALINE epoch-wise calculations, MSE calculation, BPN forward/backward pass, and the roles of δₖ and δⱼ.
