Quick Revision Notes

Revision outline based on the CST444 Module 1 topics and the uploaded Sivanandam & Deepa textbook chapter on Artificial Neural Networks.

1. Soft Computing

Soft computing uses approaches tolerant of imprecision, uncertainty and partial truth to produce robust, tractable approximate solutions. Neural networks, fuzzy logic and evolutionary computation are common methods.

2. Hard vs Soft Computing

Hard: precise inputs, well-defined models and deterministic/exact computation. Soft: approximate reasoning, adaptability, learning and tolerance to uncertainty.

3. Biological vs Artificial Neuron

Biological neuron: dendrites receive signals, cell body integrates them, axon carries the output and synapses connect neurons. Artificial neuron: inputs are weighted, summed with bias and passed through an activation function.

4. ANN Models & Connections

ANNs are processing elements connected by weighted links. Study single-layer feed-forward, multilayer feed-forward and recurrent/feedback structures, along with network connection patterns.

5. Learning Types

Supervised: input-target pairs and error comparison. Unsupervised: no teacher; discovers patterns and clusters. Reinforcement: evaluative feedback or critic information guides improvement.

6. Activation Functions

They map net input to neuron output and introduce nonlinearity.

net = Σ(wᵢxᵢ) + b

Binary sigmoid: f(x)=1/(1+e−Ax)

Bipolar sigmoid: f(x)=(1−e−Ax)/(1+e−Ax)

Ranges: binary (0,1); bipolar (−1,+1).

7. McCulloch–Pitts Neuron

A threshold-based model for binary processing. It sums weighted inputs and compares the result with threshold θ.

y=1 if Σ(wᵢxᵢ) ≥ θ; otherwise y=0

Choose weights and threshold to implement logic functions such as AND, OR and NAND.

8. Linear Separability

Classes are linearly separable when one line (2D), plane (3D) or hyperplane separates them. AND and OR are linearly separable; XOR is not separable by one linear boundary.

9. Hebb Network

Hebbian learning adjusts weights based on simultaneous input/output activation. For bipolar input and target:

Δwᵢ=ηxᵢy; wᵢ(new)=wᵢ(old)+Δwᵢ

If bias input x₀=1 is used, update its weight similarly.

Exam focus: net-input calculation, neuron comparison, learning types, sigmoid functions, M-P logic-gate implementation, XOR linear separability and Hebb weight-update tables.
